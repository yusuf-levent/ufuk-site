# ufuk-site

Marketing / product site for **Ufuk** — a desktop AI coding agent built on VS Code.

Static HTML + CSS, no build step. Deployed with **Cloudflare Pages**.

## Pages

- `index.html` — product overview and pricing (Free / Pro / Team)
- `privacy.html` — Privacy Policy
- `terms.html` — Terms of Service

## Deploy

Connected to Cloudflare Pages via Git integration: pushes to `main` deploy
automatically to `https://ufuk-site.pages.dev`.

## Notes

- Contact address is a placeholder (`hello@ufuk.dev`) — replace with the real
  support address before going live.
- Prices mirror the backend seed plans (Free $0 / Pro $20 / Team $200).
